# Codex + Ego Lite + 小红书：可复用内容 Agent

一个可以分享给其他创作者的工作流包。覆盖 **定位 → IP设定 → 对标 → 选题 → 研究 → 写稿 → 视觉与提示词 → 生图 → 发布 → 复盘**，支持单篇和批量任务。适用于知识图解、人物图鉴、教程、测评等内容；批量数量由使用者确定。

Codex负责组织与执行，浏览器负责读取和操作网站，生图工具负责画面生成，创作者负责内容取舍与验收。每篇保留版本、来源和实际结果，暂停后可以接着做。

## 定位和IP从现有账号读起

可以直接告诉Agent：“先看我的主页和代表内容，帮我整理定位与IP。”不用先填完整问卷。

Agent优先通过Ego Lite读取本人主页、简介、代表笔记及用户指定参考页面；Ego不可用时按安装指南使用Chrome + Browser Use。把页面可见事实、Agent推断与新建议分开记录，再集中补问目标读者、个人偏好和投入边界等页面无法回答的问题。

已有账号形成“当前呈现 → 保留什么 → 调整什么”的草案；新账号从用户提供的兴趣、经历、素材和参考账号形成候选。最终定位与IP由创作者确认，再用于选题、写稿和生图。分析不自动修改头像、昵称或简介。

## 先看结构

| 模块 | 要解决的问题 | 主要交付 |
| --- | --- | --- |
| 定位 | 给谁看，持续解决什么问题？ | 账号定位与内容边界 |
| IP设定 | 用什么身份、口吻和视觉被记住？ | 表达规范、品牌与资产规则 |
| 对标 | 同类内容怎样组织信息？ | 有日期和链接的样本记录 |
| 选题 | 这一篇值得讲什么？ | 选题候选与明确范围 |
| 研究 | 哪些信息有依据，哪些仍不确定？ | 证据和对象表 |
| 写稿 | 图文怎样清楚地表达判断？ | 标题、正文、图内文字 |
| 视觉与提示词 | 信息如何变成可控的画面？ | 布局、对象位置、完整prompt |
| 生图 | 实际图片是否达到要求？ | 图片、修订与检查记录 |
| 发布 | 发布了哪个版本，平台结果如何？ | 平台回读与发布记录 |
| 复盘 | 哪些反馈值得进入下一轮？ | 数据快照与改进假设 |

详细步骤见 [模块工作流](skills/xhs-content-agent/references/stages.md)。

## 开始使用

1. 解压或克隆仓库到一个新工作目录，用Codex打开。已有项目只合并需要的规则，不覆盖原有AGENTS.md。
2. 按 [浏览器安装与验证](skills/xhs-content-agent/references/browser-setup.md) 安装使用Ego Lite；出现实际兼容或连接问题时采用Chrome + Browser Use备用路线。
3. 将 `skills/xhs-content-agent/assets/templates/project.example.json` 复制为项目根目录 `project.json`。可以先只填写本人主页或参考页面链接，定位、IP和输出偏好留空；Agent读取后形成草案，确认后补全。账号标识仅在本地保存，登录密码和Cookie不写入配置。
4. 在Codex发送下面的启动指令。无需先把Skill安装到全局目录；本地入口即可使用。

> 阅读本目录AGENTS.md和skills/xhs-content-agent/SKILL.md。先检查环境，通过Ego读取我提供的本人主页、代表笔记及参考页面；Ego不可用时按指南用Chrome + Browser Use。先总结页面呈现的定位、表达和视觉，再标明推断与建议，只补问页面无法回答的关键问题。已有确认信息沿用，新定位与IP草案交我确认后用于选题。选题确认后再写稿和制定图片方案，暂不发布。

只做某一阶段也可以：

> 阅读skills/xhs-content-agent/SKILL.md，继续任务NOTE-001。以任务记录中的最新版本为准，完成写稿和视觉方案，展示完整图内文字与prompt，等我确认后生图。

可选：若需要通过 `$xhs-content-agent` 调用，将整个 `skills/xhs-content-agent` 文件夹复制到你环境实际使用的Codex技能目录。不要覆盖同名技能；刷新技能列表后确认已发现。模板和references随Skill一起保留，项目配置仍放在当前工作目录。

## 使用范围与验证边界

这是可编辑的工作流和Agent指令包，不是无人值守发帖程序。账号名、品牌、题材、对象数量、时区和预算均由使用者配置；不会沿用任何原项目的个人设定。

支持在已授权范围内连续执行。选题确认、信息与prompt确认、图文验收和发布授权分别记录；已有明确且适用本版的授权不重复索取。发布、评论、私信和删除是不同操作，授权不互相替代。

包不包含账号、登录态、Cookie、密钥、真实笔记或历史截图。分享自己运行后的项目时，只分享本包这些通用文件，另行检查新增配置、记录、图片元数据和浏览器资料。

安装指南依据2026-10-15可见的官方资料及已安装Ego技能整理。包完成了静态检查与场景审阅；接收者仍需在自己的系统完成连接、登录与只读验证，不能据此宣称已在所有环境完成发布测试。
