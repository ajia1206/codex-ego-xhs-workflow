# 批量任务

从[批量表模板](../assets/templates/batch.csv)建立任务池。总量、题材与每项规模由使用者指定，不默认书目或人数。

每条任务拥有固定ID和独立版本。研究、文案/prompt确认、图像检查、用户验收、发布和复盘分别记状态，不把“有文件”折算为“已完成”。

有价值的独立任务可以分给原生子代理，前提是当前环境支持且用户/项目指令允许。每个子任务明确输入、所有权、产物和验收条件；提醒子代理不覆盖别人修改。子代理报告建议和证据，主代理负责合并、事实复核与状态更新。默认共享账号的发布操作串行执行，避免草稿或浏览器会话冲突。

一个任务卡在资料不足或验收问题时，记录原因并继续其他独立任务。改数量、题材或范围前展示具体方案，不能为了完成率凑数据。

每次恢复先读取最新版本、真实确认记录和平台状态。对不确定提交先核验，不因重启而重新发送。网页里的“继续发布”提示不能恢复用户授权。

交付汇总分别报告：待研究、已研究、已确认方案、已出图、已验收、已发布和待解决数量。若项目尚无平台发布证据，“已完成图文”不能记为“已发布”。
