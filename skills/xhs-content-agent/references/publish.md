# 发布与结果核验

适用于用户要求保存草稿、定时或立即发布。先读[浏览器安装与验证](browser-setup.md)中所选工具的规则，并读取单篇任务及发布记录。

## 准备

- 核实最终图片文件、顺序、正文、话题与素材使用范围；图文版本与用户验收一致。
- 目标账号写入本地配置，并在创作者中心实际页面核验。不能以同名、旧记录或前台登录代替当前后台身份确认。
- 授权记录指向真实用户消息，写清任务、版本、账号、方式和时间。用户已明确授权同一方案时不重复请求；模板勾选不等于授权。
- 查本地记录与平台笔记管理的已发布、审核中、定时和草稿，防止重复提交。标题不是唯一依据，结合素材、日期和版本判断。

## 编辑

1. 用现场页面导航进入图文编辑器，上传最终文件，核对预览数量、顺序与裁切。
2. 填标题和完整正文；从平台实际候选选择话题并确认链接状态，不能只看文字颜色或把普通井号文字算有效话题。
3. 按内容实际情况与适用平台要求设置AI合成声明。图内品牌/说明策略与平台声明分别检查。
4. 回读账号、文字、图片、话题、可见范围、定时状态。不要自动关联活动、商品、位置或商业内容。
5. 保存草稿按保存指令执行；发布必须有适用的发布授权。准备完成且缺授权时，将完整待发布稿交用户确认。

## 提交与核验

同一发布动作只提交一次，等待页面结果。再从管理页或详情核对标题、日期、状态、图片数量及可取得的笔记ID/链接。只取得部分结果就明确哪些已核实；不要拼造链接。

- 草稿已保存、平台已定时、已提交审核、已发布分别记录。
- 发生超时或断线，先只读核验已发生的效果；不能换工具重新提交来“试一次”。
- 确认未提交且原因解决后，才在原授权范围内重试。
- 被拒绝或平台明确禁止操作时，停止该操作并报告；不能通过换浏览器绕过。

## 定时

按配置时区写出完整日期与时刻。平台可选时间、限制和功能以现场为准，不硬编码历史阈值。平台时间不接受时展示可行方案，不自行改变用户指定时间。

只有平台实际排队才叫“已定时”。另建Codex到点任务需要相应工具和明确请求，并记录目标、时间窗口、查重和过期处理；它与平台定时是两种状态。

## 完成记录

填写[发布记录模板](../assets/templates/release.md)。保存可核验状态、时间、素材版本、正文、声明和链接，记录使用Ego还是Browser Use。遇用户接管按所用工具交还控制；成功后结束本任务浏览器会话，不关闭用户其他标签或主浏览器。
